功能能力矩阵

          
围绕感知、理解、稳定输出和平台对接梳理核心能力，帮助使用者快速判断系统可落地范围。

        

        

          

            01
            
实时摄像头推理

            
支持未知长度视频流，不需要等待整段视频结束；滚动时序缓冲在当前帧持续输出。

          

          

            02
            
离线视频推理

            
对单个视频生成带叠加可视化的输出视频，并同步写出 JSONL 结构化结果。

          

          

            03
            
主体检测与选择

            
结合中心性、目标尺度、关键点可见性、手部可见性、轨迹年龄、稳定性和反光背心先验评分。

          

          

            04
            
连续手势理解

            
支持 SkeletonTCN、STGCN、Transformer、frame segmenter multitask 等时序模型路线。

          

          

            05
            
安全状态机

            
窗口投票、最小一致性、置信度阈值、命令保持和过期清空共同抑制抖动与误触发。

          

          

            06
            
诊断可视化

            
呈现预测、Top-K、状态机、关键点、候选轨迹和实时累计指标，便于定位错误来源。

          

          

            07
            
ONNX 导出

            
部署主线模型可导出为 ONNX，为后续嵌入式部署、TensorRT 加速和平台集成预留接口。

          

          

            08
            
多平台对接

            
结构化 JSON 输出，提供 ROS2 发布、Autoware 速度约束、CARLA planner hint 适配示例。

十步在线处理流水线

          
系统不是普通单帧手势分类演示，而是从输入到安全输出的连续理解链路。

        

        

          
01视频帧读取camera / video / keypoints

          
02候选人体检测OpenMMLab / detector

          
03姿态关键点body17 / wholebody133

          
04候选轨迹更新GreedyIoUTracker

          
05指挥主体选择OfficerSelector

          
06关键点归一化feature vector

          
07滚动缓冲SequenceBuffer

          
08时序模型推理TCN / segmenter

          
09交通语义解析gesture -> intent -> command

          
10安全状态输出hold / fallback / expiry

        

      


      

        

          
五层系统架构

          
分层结构让系统能定位错误来源，也方便替换姿态后端、扩展手势类别和接入不同车辆平台。

        

        

          
输入层摄像头、离线视频、预计算关键点统一输入源组织与基础预处理

          
感知层检测、姿态、跟踪、主体选择解决“谁在指挥”的问题

          
理解层骨架时序建模与连续动作识别解决“动作如何随时间变化”的问题

          
语义层手势、意图、控制指令、方向融合把模型结果转为交通语义

          
输出层JSONL、诊断视频、ROS2、Autoware、CARLA向下游系统稳定、规范输出

        

      


      

        

          
安全状态机与稳定输出

          
系统把模型预测和车辆命令分开处理。状态机负责过滤抖动、保持高置信命令、处理目标离开和低置信度回退。

        

        

          

            
01模型预测输出手势与置信度

            
02窗口投票最近窗口内聚合判断

            
03一致性门控满足一致性才更新命令

            
04命令保持短时不确定时保留上一命令

            
05过期回退目标消失或持续低置信时清空

min consensus6减少单帧误触发

手势标签交通语义车辆控制命令平台侧处理安全说明

            
            
              
NO_GESTURE无有效人工指挥NO_ACTIVE_COMMAND不主动覆盖规划避免无指挥误触发

              
STOP停车等待STOP速度约束 0.0 m/s最高安全优先级

              
GO_STRAIGHT允许直行GO_STRAIGHT规划器生成直行轨迹需满足持续一致性

              
LEFT_TURN_WAIT左转待转KEEP_WAIT速度约束 0.0 m/s防止误启动

              
TURN_LEFT左转通行TURN_LEFT输出方向语义由规划器确认车道可行性

              
TURN_RIGHT右转通行TURN_RIGHT输出方向语义由规划器确认行人冲突

              
CHANGE_LANE变道引导CHANGE_LANE规划器生成变道约束需要融合车道和障碍物状态

              
SLOW_DOWN减速慢行SLOW_DOWN速度约束 3.0 m/s保留制动冗余

              
PULL_OVER靠边停车PULL_OVER规划器寻找可停车区域适合检查点与人工接管

            
          

        

        
方向相关连续任务按 32 个前景类加 NO_GESTURE 组织：8 类有效交通动作乘以 4 个方向，再加 1 类无有效手势。
